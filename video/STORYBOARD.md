# 宣传视频分镜

《第二大脑》宣传片 · 16:9（1920×1080）· 30 帧/秒 · 65 秒 · 无旁白，字幕 + 代码合成的配乐和音效。

## 全片规范

- **风格**：手绘卡通。暖奶油色纸张底纹，深墨色描边，线条每秒抖动 8 次（手绘动画的"沸腾线"效果），色块略微错位。
- **配色**：奶油纸 `#F6EFE2`、墨色 `#2B2A33`；点缀色珊瑚橙、青绿、明黄、天蓝、粉、紫。主题页=青绿，项目页=天蓝，生活页=明黄，思考=紫。
- **字体**：霞鹜文楷（OFL 开源）。标题粗体，正文常规，终端用等宽版。只打包视频里用到的字。
- **主角"小脑"**：一颗粉色的卡通大脑，有大眼睛和小胳膊小腿。表情：晕乎、开心、惊喜、思考、挥手。全片形象不变，会眨眼、轻微上下浮动。
- **转场**：上一镜里的某个物体处涌出一团手绘色块盖满画面，再收缩露出下一镜，并配一声"嗖"。
- **示例内容**：全部取自仓库 `examples/` 里的虚构数据。
- **声音**：100 BPM 的轻快 lo-fi 配乐（钢琴和弦 + 贝斯 + 拨弦琶音，鼓点从第 3 镜开始）。音效：元素弹出"啵"、打字"哒"、盖章"咚"、标题"叮"。全部由代码合成，不用任何素材或 API Key。
