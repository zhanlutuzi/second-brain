随手丢进聊天框，AI 每天帮你整理成个人 wiki。

看到好文章、冒出个想法，照旧发进飞书群。电脑开着时说一句「处理收件箱」，Claude Code 会把它们编译进 Obsidian 的主题页、项目页和生活页，每条要点都标明出处。

一分钟看懂

收藏越多，脑子越乱？

1

只有堆砌，没有结构

同一个主题散落在聊天记录各处，没法串起来。

2

只有输入，没有输出

收藏完很少回看，自己的想法也没留下来。

3

想用的时候，找不到

只能在群里一页一页往上翻。

三步：收集、整理、思考

① 收集

随手发进飞书群

链接、想法、文件、图片、会议纪要，直接发。不打标签，不挑格式，不改习惯。要登录才能看的网页，用 Web Clipper 剪藏进 inbox/。

② 整理

说一句「处理收件箱」

拉取新消息、抓取网页正文，原文存进 raw/，要点编进主题、项目、生活页，每条都标明出处。处理过的消息会被加上表情，手机上一眼就能看出哪些已经入库。

③ 思考

只问你一个问题

处理完给出报告，再问你一个问题，比如「这篇你同意它哪一点？」。你的回答一字不改地记进 思考/。AI 不代写你的观点。

  1. 手机
  2. 飞书群
  3. Claude Code + kb
  4. Obsidian vault
  5. 翻 · 问 · 回顾

每天这样用

打开终端运行 kb-open，然后直接说：

处理收件箱

拉取、抓取、入库、加表情，最后给出处理报告和一个追问。

读书会的打卡功能为什么延期？

基于知识库回答，每个说法都附出处；项目类问题按日期列出决策。知识库里没有，就直说没有。

把这个回答存下来

存成一个新的主题页，以后还能接着补充。

每周回顾

本周新增了什么、你写下的话、观点有什么变化、还有哪些事没回应。只出报告，不改文件。

体检

检查失效链接、重复和矛盾的页面、iCloud 冲突副本，给出建议清单，你确认后才动手。

升级

拉取新代码、更新系统文件。你的内容和设置不受影响。

几条原则

收集零成本

沿用发群的习惯，不需要任何新操作。整理不用 24 小时开着，电脑开机时一条命令集中处理。

每条要点都有出处

主题页的要点、问答里的论断，都链接回原文。raw/ 里的原文只增不改，体检会检查有没有被动过。

你的观点只用你的原话

「我的看法」和 思考/ 里只放你自己说的话。AI 负责归类和链接，不润色、不代写。

内容属于你

全部是普通 Markdown 文件，放在你自己的 iCloud 里，手机上用 Obsidian 也能看。个人内容永远不会进入这个仓库。

多台电脑接力

处理进度跟着知识库一起同步，任何一台装了 kit 的电脑都能接着处理，不会重复拉取。密钥只存在本机。

开源、可升级

MIT 许可。规则写在文件里而不是聊天窗口里，kb upgrade 一条命令升级，你的个人补充会保留。

15 分钟装好

准备一台 Mac，装好 Homebrew、Node.js、Claude Code 和 Obsidian。

  1. 下载 kit：

    git clone https://github.com/zhanlutuzi/second-brain.git ~/second-brain-kit

  2. 在 kit 目录里启动 Claude Code：

    cd ~/second-brain-kit && claude

  3. 输入 /setup，一问一答走完。它会检查环境、新建知识库、配置飞书（可以先跳过），再用 20 条示例数据试跑一次。

每天怎么用、升级会动什么、常见问题，见使用说明。
