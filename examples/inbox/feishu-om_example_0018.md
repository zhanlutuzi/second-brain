# Dataview：把笔记的属性变成可查询的表格

Dataview 是 Obsidian 的一个社区插件。它可以读取每篇笔记开头的 YAML 属性，然后像数据库一样查询，生成动态的表格和列表。

例如，你可以列出所有"类型为主题、最近一周更新过"的页面，或者统计每个标签下有多少篇笔记。查询结果会随着笔记的修改自动更新。

作者提醒，Dataview 的查询只在 Obsidian 里显示，导出或在别的编辑器里打开时看不到结果，所以重要的信息仍然应该直接写在正文里。
