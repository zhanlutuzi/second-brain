# 用整块时间做深度工作

深度工作指的是在不受打扰的状态下，把注意力长时间集中在一件有难度的任务上。作者认为，这种能力越来越稀缺，也越来越值钱。

文章建议每天安排一到两个九十分钟的整块时间：提前决定这段时间只做哪一件事，关掉消息通知，把手机放到另一个房间。开始时可能只能坚持三十分钟，但专注力像肌肉一样，可以逐步练出来。

作者特别提醒，深度工作的敌人往往不是大的干扰，而是"顺手看一眼"的小习惯。每次切换任务，注意力都要花十几分钟才能完全回来。
