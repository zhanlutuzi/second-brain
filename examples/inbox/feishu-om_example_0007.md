# 本地优先软件：数据应该首先属于你自己

"本地优先"指的是软件把数据首先保存在用户自己的设备上，云端只用于同步和协作，而不是唯一的数据存放地。

作者列举了它的几个好处：离线也能用；打开和搜索都很快；即使服务商倒闭或者停止服务，数据仍然在你手里；数据格式通常更开放，方便迁移。

难点在于同步：多台设备同时修改同一份数据时，如何自动合并而不丢内容。作者认为，以纯文本为主的工具在这方面有天然优势，因为文本的差异容易比较和合并。
