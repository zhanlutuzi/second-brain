# ripgrep：比 grep 更快的命令行搜索工具

ripgrep（命令名 rg）是一个开源的命令行搜索工具，用来在大量文件中搜索文本。它默认会跳过 .gitignore 里忽略的文件和二进制文件，速度通常比传统的 grep 快得多。

常用写法：rg 关键词 目录，就能列出所有匹配的行和文件名；加 -l 只列文件名；加 -i 忽略大小写。

作者推荐把它和笔记软件配合使用：在几千个 Markdown 文件里查找一个词，几乎是瞬间完成。
