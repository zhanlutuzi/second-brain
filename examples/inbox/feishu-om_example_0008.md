# 纯文本是最长寿的文件格式

作者回顾了自己二十年来用过的笔记软件，发现大多数专有格式的笔记都已经很难打开，只有纯文本和 Markdown 文件至今还能直接阅读。

文章认为，个人知识库应该优先选择纯文本格式：任何编辑器都能打开，可以用版本控制记录每一次修改，也可以用命令行工具快速搜索。

作者也承认纯文本的局限，比如图片和表格不够方便。他的做法是：正文一律用 Markdown，图片单独放在一个附件文件夹里，在正文中用相对路径引用。
