# 写好提示词的三个结构要素

作者把一个好的提示词拆成三部分：背景（模型需要知道的上下文）、任务（具体要做什么、做到什么程度）、输出格式（结果长什么样）。

文章发现，很多效果不好的提示词，问题都出在背景不足：写提示词的人默认模型知道自己的处境，但模型其实一无所知。

作者建议，把反复使用的背景和规则写成文件，每次让模型先读文件，而不是每次在对话里重新解释。这样既省力，结果也更稳定。
