# 咖啡因对睡眠的影响比你想的更久

咖啡因在体内的半衰期大约是五到六个小时。也就是说，下午三点喝的一杯咖啡，到晚上九点仍有一半左右的咖啡因留在体内。

文章指出，即使能顺利入睡，咖啡因也可能减少深度睡眠的比例，让人第二天醒来仍然觉得疲惫，进而喝更多咖啡，形成循环。

作者建议把最后一杯含咖啡因饮料的时间提前到中午之前，并观察一两周的睡眠变化。本文仅为科普示例，不构成医疗建议。
