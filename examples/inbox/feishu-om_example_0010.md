# 提示词里的示例：给一个好例子胜过十条规则

文章讨论了在提示词中给出示例的作用。作者的经验是：当你希望输出遵循某种固定格式时，直接给一个完整的示例，比用文字描述格式要可靠得多。

但示例也有副作用：模型可能过度模仿示例的内容，而不仅仅是格式。作者的对策是给两到三个内容差异较大的示例，并明确说明"只参考格式"。

作者还建议定期检查提示词里的规则是否互相矛盾，规则越多，越容易出现冲突。
