# 什么值得做成记忆卡片

很多人开始用间隔重复软件后，很快就积累了几千张卡片，然后放弃。作者认为问题出在"什么都往里放"。

文章给出三条筛选标准：第一，这条知识你在未来一年里大概率会用到；第二，它不容易随时查到，或者查一次的成本很高；第三，它能帮你理解别的知识，而不仅仅是一个孤立的事实。

作者还建议，卡片应该围绕"理解"来写：与其记一个定义，不如问"它和某个相近的概念有什么区别"。这样复习时，你回想的是一张关系网，而不是一个词条。
