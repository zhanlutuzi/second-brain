# 间隔重复入门：为什么复习的时机比次数重要

遗忘曲线告诉我们，新学的内容在最初几天忘得最快，之后逐渐放缓。间隔重复的做法是：在快要忘记的时候复习一次，每复习成功一次，下次复习的间隔就拉长一些。

文章用一个例子说明：同样复习五次，集中在一天里完成，一个月后的记忆效果远不如分散在一个月里完成。关键在于每次复习都需要"费力地回想"，而不是重新看一遍。

作者推荐的入门方法是：每天固定十五分钟，只复习到期的卡片；卡片的问题要具体，一张卡片只问一件事；答不出来的卡片不要跳过，而是缩短它的间隔。
