# 提问

只根据 wiki 和 raw 中的内容作答。页面格式见 CLAUDE.md。全程用中文。

## 步骤

1. **定位**：读 `index.md`，根据标题和摘要找出可能相关的页面。再用 `rg -l "<关键词>" 主题 项目 生活 思考` 补充搜索 2–3 个关键词。
2. **阅读**：读这些页面。需要细节或核实时，再读页面 `sources` 里引用的 raw 文件。
3. **作答**：
   - 每个论断后面都附上依据，写成 `[[页面]]` 或 `[[raw/...]]` 链接。
   - 区分来源的观点和用户自己的看法："我的看法"和 `思考/` 里的内容要说明"这是你在 某日 写下的"。
   - 项目类问题（例如"为什么延期"）按日期排列决策时间线，每条附原始会议记录的链接。
   - 知识库里找不到依据的，直接说"知识库里没有相关内容"。**不要用常识补充冒充知识库内容。** 如果你确实想补充常识，单独放在最后，标明"以下不是来自知识库"。
4. **存档（仅当用户要求时）**：用户说"把这个回答存下来"之类的话时：
   - 用主题模板在 `主题/` 下新建页面，标题就是问题的主题；
   - 正文写回答内容，"要点"中每条仍要带 raw 来源；
   - frontmatter 的 `sources` 列出回答中引用过的 raw 文件；
   - 在被引用页面的"相关"里加上新页面的链接；
   - 运行 `kb index`，然后 `kb commit -m "[YYYY-MM-DD] 提问存档 | <页面名>"`。

不要因为提问而修改任何已有页面的内容，除非用户明确要求。
