# 每周回顾

页面格式见 CLAUDE.md。全程用中文。**只输出报告，不修改任何文件，不提交。**

## 步骤

1. 运行 `kb status`，记下 `today` 和 `pending_question`。
2. 读 `log.md`，取出日期在最近 7 天内（含今天）的记录。
3. 读 `思考/` 中覆盖这 7 天的月份文件（例如 `思考/2026-10.md`），取出这 7 天的原话。
4. 读本周新建或更新过的页面（log 中提到的页面，或 frontmatter `updated` 在这 7 天内的页面）。
5. 对每条本周的原话，读它关联页面的"我的看法"里更早的记录，看是否存在冲突或明显的变化。

## 报告格式

```
## 本周回顾（MM-DD — MM-DD）

### 新增概览
- 处理收件箱 N 次，入库 M 条
- 新建页面：[[页面]]、[[页面]]
- 更新最多的主题：[[页面]]（K 次）

### 你写下的话
- MM-DD：原话 → [[关联页面]]

### 观点变化
- [[页面]]：MM-DD 你说"……"，本周你说"……"

### 待回应
- 上次的追问：……
- 处理报告里的待确认事项：……
```

- 原话一字不改地引用，不总结、不评价。
- 没有冲突就写"本周没有发现与以往看法冲突的地方"，**不要硬凑**。
- 没有内容的小节直接省略。
- 最后可以提一句建议，例如某个主题本周更新很多、值得写一段自己的看法，但不要替用户写。
