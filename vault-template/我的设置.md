# 我的设置

这是整个知识库里唯一需要你自己修改的文件。上面的属性由系统读取，下面的正文可以随便写备注。

| 属性 | 含义 |
| --- | --- |
| feishu_chat_id | 飞书收件箱群的 ID（以 oc_ 开头），运行 /setup 时自动填写 |
| reactions | 处理成功、失败时给飞书消息加的表情 |
| browser_domains | 直接用浏览器抓取的域名，例如公众号 |
| projects | 你在做的项目，会议记录会归到同名的项目页，例如 [示例项目A, 示例项目B] |
| life_categories | 生活页的分类 |
| batch_limit | 每次处理收件箱最多处理多少条 |
| lint_interval_days | 距离上次体检超过多少天就提醒 |

App ID 和 App Secret 不写在这里，它们保存在 `~/.second-brain/.env`，不会同步到手机，也不会进入版本记录。
